Write one function, the hazard, and get a full probability distribution that a Bayesian sampler can score and simulate from. For developers with some statistics: the interface, how it is computed, and why it had to be a distribution.

JointSurvivalModels.jl is a Julia package that turns a hazard function into a full probability distribution: you write one function, and you get logpdf, ccdf, rand and censoring, ready for a probabilistic programming language. Its main use is joint models of survival and longitudinal data, which have no closed-form density. I wrote it during my master’s thesis with Roche; version 1.0 was released in February 2024 under Roche’s open-source organisation insightsengineering and is in Julia’s package registry:

using Pkg
Pkg.add("JointSurvivalModels")

This page is about the software: the interface and how it is computed. For the statistics behind it (the hazard, the likelihood, model checking), see the post on the thesis.

The problem, as an interface problem

A sampler such as Turing.jl’s NUTS asks two things of every observed quantity: a log-density, to score parameters, and a way to draw samples, to simulate from the fitted model. For the usual distributions both are formulas.

Survival models are specified differently, by their hazard h(t)h(t): the event rate at time tt among those who have not had the event yet. The density follows from it, but through an integral:

f(t)=h(t)exp⁡(−∫0th(u)du).f(t) = h(t)\,\exp\Big(-\int_0^t h(u)\,du\Big).

In a joint model the hazard contains a patient’s biomarker curve, for example tumour size over time, and that curve is non-linear. The integral then has no closed form. The R packages for joint models avoid it by restricting the curve to linear models. The alternative is to compute it numerically, which raises the question of where that code lives so that the sampler still sees an ordinary distribution.

One method to implement

The package answers with an abstract type. Subtype HazardBasedDistribution, implement hazard, and the rest of the Distributions.jl interface is derived:

struct LogLogistic <: HazardBasedDistribution
    α::Real
    β::Real
end

JointSurvivalModels.hazard(d::LogLogistic, t::Real) =
    (d.β / d.α) * (t / d.α)^(d.β - 1) / (1 + (t / d.α)^d.β)

What you get, and how:

Method Computed as
cumulative hazard H(t)H(t) ∫0th(u)du\int_0^t h(u)\,du by adaptive Gauss–Kronrod quadrature
ccdf (survival) e−H(t)e^{-H(t)}
logpdf log⁡h(t)−H(t)\log h(t) - H(t)

Because the type is a ContinuousUnivariateDistribution, everything written against that interface works unchanged. That includes Distributions.jl’s censored, which is how a survival time whose event was never observed enters a model.

Joint models on top

JointSurvivalModel is the ready-made subtype, with the hazard

h(t)=h0(t)exp⁡(γ⊤L(M(t))+β⊤x)h(t) = h_0(t)\,\exp\big(\gamma^\top L(M(t)) + \beta^\top x\big)

for any baseline hazard h0h_0, any number of longitudinal models MM with their links LL, and covariates xx. All of them are plain Julia functions of time:

jm = JointSurvivalModel(t -> 0.2, 0.5, cos)   # h(t) = 0.2 · exp(0.5 · cos t)

Inside a Turing model, a patient’s censored survival time is one line. sld is the tumour-size curve and Ψ[i] are that patient’s parameters, sampled in the same model:

surv_times[i] ~ censored(JointSurvivalModel(h₀, γ, t -> sld(t, Ψ[i])), upper = censoring)

Why a distribution

My first working joint model added the survival log-likelihood by hand with @addlogprob!. It sampled correctly and still was a dead end: the framework no longer knew which observation a term belonged to, so leave-one-out cross-validation did not work, and with nothing to call rand on, neither did predict. Making the model a distribution fixed both at once. That is the whole package: about 200 lines that compose Integrals.jl, DifferentialEquations.jl and Roots.jl behind the Distributions.jl interface.

A worked case study

The repository reproduces the oncology model of Kerioui et al. (2020): a non-linear mixed-effects model of tumour size, an exponential baseline hazard and an identity link. On their simulated data of 100 patients, 2,000 NUTS draws recover the parameters the data were generated with. The link coefficient comes out at γ=0.0103±0.0012\gamma = 0.0103 \pm 0.0012 against a true 0.010.01, with R^≈1\hat R \approx 1 throughout.

Because the distribution can also be sampled, the same fit gives individual predictions: a patient’s tumour trajectory, and their survival conditional on having survived to their last visit.

I wrote the package.
